# 应用管理器

入口：**文件页左上角的方格图标**（`square.grid.2x2`）。它是一个 sheet，内部自带导航，用来把「已安装 App」当成一等公民来浏览。

## 能做什么

| 操作 | 行为 |
| --- | --- |
| 列表 | 列出扫描到的所有 App：图标 + 桌面名字 + bundle id（等宽）+ 版本 + 数据容器路径 |
| 搜索 | 顶部搜索框，按 **App 名**或 **bundle id** 过滤 |
| 点一行 | 进详情页：大图标、bundle id、版本、包体路径 / 数据容器路径 / 可执行文件路径（点路径即复制），以及下面的操作按钮 |
| **长按一行** | 快捷菜单：**打开 .app 目录**、**打开数据容器**、复制 bundle id、复制路径、**设为替换页目标 App** |
| 打开 .app 目录 / 数据容器 | 切到「文件」页并定位到该路径（复用同一个浏览状态），方便直接翻包体或数据容器 |
| 设为替换页目标 App | 切到「替换」页并把它选为目标（替换页接住这次请求后会自动重新匹配本地文件） |
| 下拉刷新 | 强制重新扫描（`AppScanner.installedApps(force: true)`） |
| 权限变化自动刷新 | 激活内核成功 / 提权成功时，`EnvironmentProbe.notifyFileSystemAccessChanged()` 会清掉 `AppScanner` 缓存并广播通知，本页自动重扫（不用再去别的页面逛一圈） |

## 图标是怎么来的（三级回退，任何一步失败都不会崩）

1. **包内图标文件**：`AppScanner` 在 `.app` 里找 `AppIcon60x60@2x.png` 这类松散图标，命中就用 `UIImage(contentsOfFile:)` 读；
2. **系统私有接口**：`NSClassFromString("LSApplicationProxy")` → `applicationProxyForIdentifier:` → `iconDataForVariant:`（用 `method(for:)` 取 IMP 直接调，因为参数是 `int`，`perform(_:with:)` 传不了），依次试 variant `2 / 3 / 1 / 0`；
3. **占位图标**：都拿不到就画 `app.fill` + 灰底，**不留空白**。

图标在后台线程加载，`NSCache` 按 bundle id 缓存，回调统一在主线程。

## 「这是哪个 App 的目录」横幅

文件页与替换页的目标目录浏览器都会用同一套解析：

- **包体**：`/var/containers/Bundle/Application/<UUID>/<X>.app`（含子路径）
- **数据容器**：`/var/mobile/Containers/Data/Application/<UUID>`（含子路径）

命中时列表顶部出现一条横幅：**App 图标 + 桌面名字 + 「包体 / 数据容器」标签 + bundle id**，同时把导航标题换成 App 的桌面名字；解析不出来时静默不显示（不弹错）。

解析方式只认**容器 UUID**：从 `AppScanner` 的 `bundlePath` / `dataPath` 里抽出 UUID 建字典，查一次 O(1)，不做全盘扫描；`AppScanner` 自己有 60 秒缓存，解析器跟着它的结果走。

## 权限要求（0.8.0 起列表本身不再需要权限）

**列表**和**容器内容**是两件事：

| | 需要什么权限 | 说明 |
| --- | --- | --- |
| **列出 App（名字 / 图标 / 容器路径）** | **不需要任何权限**（0.8.0 起） | 走私有接口 `LSApplicationWorkspace`（`defaultWorkspace` → `allInstalledApplications`），全部运行时查找 + `dlopen`，**不链接私有框架**；每个字段单独 `@try/@catch`，缺字段就少字段 |
| **读容器里的文件** | 需要激活访问（内核逃逸 / MHA 零内核 / 越狱环境） | 没权限时点进目录会明确提示「需要先激活访问才能读取容器内容」，**不留白** |

有文件系统访问时，`AppScanner` 会用**容器扫描**（读 `metadata.plist` + `Info.plist`）的结果**覆盖**系统接口那份 —— 路径、可执行文件名、图标都更准。两路合并后的来源统计会写进日志：

```
AppScanner: 扫描到 43 个 App（来源=LSApplicationWorkspace + 容器扫描；LSApplicationWorkspace=43 个，容器扫描=12 个，文件系统访问=是，未越狱，uid 501）
```

应用管理器在没权限时会在列表顶部显示一条说明横幅（「App 列表来自系统接口（不需要权限）」），而不是以前的整页空状态。

## 已知限制

- 图标依赖私有接口 `LSApplicationProxy`：接口改名或拿不到时回退到包内图标文件，再不行就是占位图标（**功能不受影响**）；
- 数据容器映射靠 `.com.apple.mobile_container_manager.metadata.plist` 里的 `MCMMetadataIdentifier`（`AppScanner` 扫描时建立），个别 App 没有数据容器时列表里显示「无数据容器」；没权限时这份映射拿不到，列表里的容器路径来自系统接口；
- App 列表与「替换」页共用同一份扫描结果（60 秒缓存），刚装/刚删的 App 下拉刷新即可看到；
- 只能浏览、复制路径、打开目录、设为替换目标——**不在应用管理器里直接删/改 App**（要改文件请用「替换」页或「文件」页，那两处有备份与回滚兜底）。
- 系统接口给不出可执行文件名（`CFBundleExecutable`），此时「可执行文件」一栏显示的就是包体路径本身（不会出现 `xxx.app/` 这种带尾斜杠的假路径）。
