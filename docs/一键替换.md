# 一键替换（「替换」页）

> 目标：把本地准备好的文件，替换进**已安装 App 的数据容器**里同名文件的位置，全程自动备份、可一键回滚。
> 这一页只是把你手动做的「选目标 → 找文件 → 覆盖」变成向导；**真正的替换逻辑没有新写**，交给现有引擎 `RecipeRunner`，所以备份/记录/回滚语义和脚本页的配方**完全一致**。

## 一、怎么用（四步）

1. **选目标 App**
   - 「目标 App」区列出扫描到的已安装 App（显示名 + bundle id + 数据容器路径）。
     **激活成功（或提权成功）后会立刻作废缓存并自动重扫一次**；也可以随时点区里的「重新扫描 App」手动重扫。
     列表为空时会给明确出路（先去设置页激活，或点重新扫描），不会只显示一句没有下文的「获取到 0 个 app」。
   - 单选：点一下选中（列表是**固定高度、内部可滑动**的，不再撑满整屏）；选中后只留那一行 + 「**更换目标 App**」按钮，点它取消重选；App 多于 25 个时区里会出现一行过滤框（按名字或 bundle id）。
   - 目标来自 `AppScanner`：包体读 `/var/containers/Bundle/Application/<UUID>/<Name>.app`，数据容器读 `/var/mobile/Containers/Data/Application/<UUID>/`（靠容器元数据里的 bundle id 对应）。

2. **加文件 / 文件夹（两种方向，任选）**
   - **目标优先（推荐）**：点「**添加目标文件 / 文件夹**」→ 在目标 App 的目录里挑出**要被替换掉的文件或文件夹**（文件模式默认从数据容器开始；包体模式根锁定为 `.app`）。**点文件=选中（可多选）、点文件夹=进入、长按文件夹=把它选为目标；右上角「确定」= 有选中就提交选中的，没选中就把当前所在目录当目标**。App 会立刻在**本机 Documents**（含 `ReplaceSources/`，跳过 `Backups/`、`Runs/`、`Logs/`、`ImportInbox/` 等系统目录）里找同名源配上（文件配文件、文件夹配文件夹）：
     - **唯一同名** → 直接绑定，且**目标路径被锁定**（自动匹配不会再把它改掉）；
     - **同名多处** → 点那一行，从候选里挑一个本地文件；
     - **一个都没有** → 直接弹本机「文件」选择器，选完自动绑到刚才那个目标上。
   - **本机优先**：点「**添加本机文件**」→ 系统「文件」选择器（UIKit；**一律 `asCopy:NO`**——Apple 不允许用 asCopy 选文件夹，用户一旦选中文件夹就会抛 `folder import is not supported`；选完由 App 用安全作用域把内容拷进沙盒，iCloud 未下载的文件会先经 `NSFileCoordinator` 协调下载）。
   - 选中的文件会**拷进 App 自己的 `Documents/ReplaceInbox/`**，重名自动改名（`config-1.json`）。
   - 这个目录里的文件会在下次进页时自动列出，所以关机/杀后台都不会丢。

3. **确认目标路径（三条路）**
   - 选好目标 App 后，会在它的**数据容器里递归遍历一次**，按**文件名**建立索引，然后给每个本地文件自动绑定：
     - **唯一同名** → 自动绑定，行里显示 `→ /完整/目标/路径`；
     - **同名多处** → 行尾橙色感叹号，**点这一行**从候选列表里选一个；
     - **没找到** → 行尾红色感叹号，**点这一行**打开「浏览目标 App 目录」自己找。
   - **浏览目录**：sheet 里默认是**数据容器**，顶部可切到**包体**；可进子目录、看面包屑（等宽、中间截断），**点文件=选中、点文件夹=进入、长按文件夹=选为目标**；右上角「确定」的规则见第六节。没权限时会明确提示（去激活内核，或说明当前是越狱 / TrollStore 环境），不会白屏。
   - **手填**：长按该行选「手填完整路径」（也可以一键「用数据容器 + 这个文件名」）；长按菜单里还有「清除绑定」。
   - 匹配上限：最多扫描 20 万项、同一个文件名最多保留 12 个候选（避免大容器把界面拖死）。
   - 左滑把条目从列表移除（**文件本体留在 `ReplaceInbox`**，不会删）。

4. **开始替换**
   - 主按钮上方有 **「执行前自动备份」** 开关（默认开，状态会记住）；关掉后日志里会先打一条橙色警告，且这次运行**无法回滚**。
   - 底部主按钮「开始替换」。运行中按钮内嵌小菊花、文字变「替换中…」并禁用。
   - 按钮上方有一行**权限状态**：绿勾 = 已具备沙盒外读写（内核逃逸已激活，或越狱 / roothide / TrollStore 环境）；橙色警告 = 还没有。
   - **没权限就点**：不会静默失败，会弹提示并让你去「设置」页点『激活内核访问』。

## 二、备份与回滚的确切语义

执行时会把向导里的 (本地文件 → 目标路径) 组装成一份内存里的配方，交给 `RecipeRunner`，选项固定为：

| 选项 | 值 | 含义 |
| --- | --- | --- |
| `backup` | **由页面开关决定**（默认 true） | 每个**将被覆盖**的目标，执行前整份拷进 `Documents/Backups/<yyyyMMdd-HHmmss>-一键替换/`；**关掉就没有回滚兜底** |
| `fixOwnership` | **true** | 写之前把目标**父目录**属主改成 `mobile:mobile`（走内核接口），写之后再修目标自身 |
| `stopOnError` | **true** | 某一步失败就停下，但**已经备份的原件仍可回滚** |
| `killTarget` | **false** | 向导不结束目标 App 进程；需要它重启加载配置，请去「脚本」页写一条带 `kill` 的配方 |

- 备份目录里是 `manifest.json` + `files/00N-<文件名>`，并由记录页统一管理。
- **运行记录**：每次替换都写 `Documents/Runs/<yyyyMMdd-HHmmss>-一键替换.json` 与同名 `.log`。
- **回滚**（页内「一键回滚这次替换」或「记录」页对应备份）：
  - 覆盖前存在的文件 → 先把原件拷回原位，再恢复原来的 `mode` 与 `uid:gid`；
  - 覆盖前**不存在**的目标（本次新写进去的）→ 回滚时**删掉**它；
  - 有任意一条失败会报「部分文件回滚失败」，成功的那些**不会自动退回**。
- 回滚**不会**恢复：`chmod`/`chown` 单独改过的权限（向导不产生这类步骤）、以及内核层面的任何状态。

## 三、边界（务必先读）

1. **`/System`、`/usr` 仍是只读**：SSV 签名卷，任何工具都改不了。能改的是 `/var`（数据容器、Preferences、Caches 等）。
2. **root 属主的目标**：先到「设置」页点『提权到 root』（把本进程凭据换成 uid=0）再替换；这条路径单独自检，失败会明确报错。
3. **改自签 App 包体有风险**：替换 `.app` 里的**资源文件**通常没事，但改到主可执行文件或让整包校验失败，App 可能直接打不开，最坏要重装。**向导默认建议只动数据容器**（`{app.data}` 下）。
4. **激活是「每个进程一次」**：App 完全退出或被杀后，需要重新点一次「激活内核访问」。
5. **目标 App 正在运行时**：替换它的数据文件一般没问题（只是它可能把旧内容写回内存），需要它立刻生效就用脚本页的 `kill` 步骤或手动重启它。

## 四、排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 点「开始替换」弹「还没激活内核访问」 | 到「设置」页点『激活内核访问』，成功后再回来 |
| 某个文件行是红色「没找到同名文件」 | 目标 App 里确实没有同名文件；点该行手填完整路径（可作为新文件写入，同样会备份） |
| 某个文件行是橙色「同名多处」 | 点该行从候选里挑一个正确的 |
| 替换步骤显示失败 | 看页内日志；常见原因是父目录还没拿到内核权限（先提权）或路径写错 |
| 想撤销 | 页内「一键回滚这次替换」，或在「最近的替换」/「记录」页找到那条备份点回滚 |

## 五、结果卡片与「最近的替换」（0.3.1 起）

- 每次执行后给一个**结果卡片**：绿色对勾「替换成功」或红色「替换未完全成功」+ 摘要 + 备份 id，动作有「查看运行记录」和「一键回滚这次替换」。
- 新增 **「最近的替换」** Section：只列**本页**产生的替换记录（按运行名 `一键替换` 过滤，最多 8 条），每条三个动作：

| 动作 | 行为 |
| --- | --- |
| **回滚** | 走 `RunStore.restore(_:)`，与「记录」页完全同一套：先把原路径父目录属主改回可写 → 原件拷回 → 还原 `mode` 与 `uid:gid` → 本次新建的文件删掉。点之前弹二次确认 |
| **查看日志** | 直接看那次运行的 `.log` 全文，可一键复制 |
| **删除记录** | 删掉 `Runs/` 下对应的 `.json` 与 `.log`（**不动备份**；要删备份去「记录」页） |

- 当次**关掉了自动备份**的话：结果卡片和这一行都会显示「没有备份 / 无法回滚」，回滚按钮不可用并说明原因。

## 六、文件夹模式（0.4.0 起：目标里多出来的文件可选「保留 / 删除」）

替换页顶部有「替换方式」分段选择：**文件模式 / 文件夹模式 / 包体(.app)模式**。三套绑定互不干扰，各自记住自己的内容（模式本身也持久化）。

用法：

1. **源文件夹**：点「添加文件夹…」，从「文件」App 选一个文件夹；选完由 `DSPickers.presentFolderPickerCopying` 用**安全作用域 + `NSFileCoordinator`** 整份递归拷进 `Documents/ReplaceSources/<名字>/`（`asCopy:NO`，因为 Apple 不允许 asCopy 选文件夹；大文件夹拷贝需要一点时间，界面会短暂无反应）；
2. **目标文件夹**：点源文件夹那一行打开目标目录浏览器（默认根 = 数据容器，顶部可切包体），进到要替换的那个文件夹，点右上角 **「选择此文件夹」**；
3. 点「开始替换」。

> **目录浏览器的统一规则（0.4.0 起，三种模式完全一致）**
> - **点文件行** = 选中 / 取消选中（**可多选**：行尾打勾，Section 标题显示「已选 N 项」，下方有「清除选择」）。
> - **点文件夹行** = 进入该目录；**长按文件夹行** = 「选为文件夹目标」（把那个文件夹本身当目标）。
> - **右上角「确定」永远可用**（只要路径非空、有文件系统权限）：
>   - **有选中项** → 提交**全部选中项**（文件与文件夹可以混选，一次绑多条）；
>   - **没有选中项** → 提交**当前所在目录**（= 选当前文件夹；在根目录按它就是整个 `.app` / 数据容器）。
>   工具栏菜单里另有「选择当前文件夹」与「清除选择」两个等价入口。
> - **目录切换用克制的淡入淡出**（0.18 秒 `easeOut`，不做全宽位移——位移叠加异步加载会闪/顿）；「文件」页同样生效，且不动 List 的 identity（排序/搜索/编辑/多选/滚动位置不受影响）。
> - 切换目录时**不会把列表换成转圈**：保留上一级内容，只在上面显示一行「正在读取…」，避免闪出半屏空白。

**「目标文件夹里多出来的文件」怎么处理**（执行区的一个选项，三种模式共用，只对文件夹类目标生效）：

| 选项 | 行为 | 底层 op |
| --- | --- | --- |
| **保留**（默认，最安全） | 只把源里有的文件写过去（**只覆盖同名项**），目标文件夹里其余文件保持不动 | `mergeDir` → `FileOperations.mergeDirectory` |
| **删除** | 让目标文件夹与源保持一致：先整棵备份，再删掉目标现有内容，把源整棵拷过去（**目标里源没有的文件会被移除**） | `replaceDir` → `FileOperations.replaceDirectory` |

| 环节 | 行为 |
| --- | --- |
| 备份 | 两种选项都先把**整个目标文件夹递归备份**（`BackupSession.capture(path, recursive: true)`） |
| 目标原本不存在 | 直接创建；同时登记一条 `existed: false` 的备份条目，**回滚会把它删掉** |
| 自动备份开关 | 只要任务里有**文件夹类目标**就**强制为开且不可关**（关掉就没有兜底） |

## 七、自动化任务（0.3.4 起：保存配置 + 你自己运行）

「替换」页的「自动化任务」Section 是**保存配置 + 手动运行**：App 不会在后台、也不会在启动时自动改文件（0.3.2 里那两个自动开关已经去掉）。

用法：

1. 先在页面上选好模式、目标 App、替换内容与目标路径；
2. 点 **「保存当前设置为自动化任务」** → 弹框里给任务起名（默认「App 名 · 模式 · 时间」）→ 保存；
3. 之后在任务列表里点那一行的 **「运行」** 即执行；长按一行可「载入编辑 / 重命名 / 删除」。

| 项 | 行为 |
| --- | --- |
| 存储位置 | `Documents/AutoTasks/tasks.json`（`Codable` JSON，可直接查看或备份） |
| 旧格式迁移 | 0.3.3 及之前的 `Documents/AutoTasks/auto.json` 会在启动时自动迁移成一条保存任务，然后把旧文件改名为 `auto.json.bak`（只迁一次，不丢配置） |
| 强制备份 | 运行时一律把 `backup` 置为 true；每次写运行记录（`Runs/`）并出现在「最近的替换」里，可一键回滚 |
| 环境门 | `EnvironmentProbe.hasFileSystemAccess()` 为假（既没逃逸、也不是越狱环境）→ **不执行**，日志与结果卡片写明「请先激活内核访问」；**不会**自动去跑漏洞 |
| 并发门 | 已经有一次替换在跑（手动或任务）→ 不重复触发 |
| 列表显示 | 名字 / 模式 / N 项 / 备份状态 / 目标路径；任务里含文件夹类目标时额外显示「多出文件：保留 / 删除」 |

## 八、包体(.app)模式（0.4.0 起：在 .app 内部挑文件 / 文件夹）

> **0.4.0 起这个模式的含义变了**：它**不是**「替换整个 .app」，而是**在 `.app` 内部选择要替换的文件（可多选）和文件夹**，把它们当成目标；每个目标自动在本机按同名配源。

| 项 | 说明 |
| --- | --- |
| 目标范围 | 所选 App 的包体 `/var/containers/Bundle/Application/<UUID>/<Name>.app` **内部**（浏览器的根锁定在这个 `.app`，可以一层层进子目录） |
| 主要入口 | **「添加目标文件 / 文件夹（浏览 .app）」** → 在 `.app` 里挑文件（多选）或文件夹 → 自动配本机同名源（文件配文件、文件夹配文件夹；没有同名就点那一行挑） |
| 次要入口 | **「添加本机文件（按名自动匹配 .app 内目标）」**：先加本机文件，再按文件名在 `.app` 里找目标 |
| 文件夹目标 | 可多个：每个 `.app` 内的文件夹对应一个本机同名源文件夹；没配上的行显示「还没配本机源文件夹：点这一行挑一个」 |
| 多出来的文件 | 由执行区的 **「目标文件夹里多出来的文件：保留 / 删除」** 决定（默认保留 = 只覆盖同名文件） |
| 强制备份 | 含文件夹类目标时「执行前自动备份」强制为开且不可关（`.app` 可能很大，备份会占空间、耗时） |
| 底层 op | 保留 = `mergeDir`，删除 = `replaceDir`（见 `docs/脚本格式.md` 第四节）；回滚仍然只有一套 `RunStore.restore` |

> ⚠️ **风险**：改自签 App 的包体会破坏它的签名校验，**可能导致 App 直接打不开**；动手前确认你有重装手段。回滚可用，但需要备份完好。

## 九、目标优先绑定（0.3.7 起；0.4.0 起支持文件夹与多选）

**为什么要它**：以前只能「先加本机文件 → 再去找目标」，方向反了；实际上用户往往是**先看到目标 App 里那个要换掉的文件 / 文件夹**，再想「用我这份换掉它」。

| 入口 | 打开的是 | 说明 |
| --- | --- | --- |
| **添加目标文件 / 文件夹**（文件模式） | **目标 App 的数据容器** | 点文件=选中、点文件夹=进入、长按文件夹=选为目标；右上角「确定」= 有选中就提交选中的、没选中就提交当前目录 |
| **添加目标文件 / 文件夹**（包体模式） | **目标 App 的 `.app`**（根锁定） | 同上 |
| **添加本机文件**（两种模式都有） | **本机「文件」选择器** | 原来的「本机优先」流程，按文件名自动匹配目标 |

绑定规则（选完目标之后自动发生）：

1. 目标是**文件夹** → 在本机 `Documents/ReplaceSources/` 里按**同名**找源文件夹：找到就直接配好；没找到就加一行「还没配本机源文件夹」（点它挑）；
2. 目标是**文件** → 在本机 `Documents/`（含 `ReplaceSources/`）里按**同名**查找，**跳过** `Backups/`、`Runs/`、`Logs/`、`ImportInbox/`、`Adapted/`、`Artifacts/`；
3. **唯一命中** → 直接绑定，目标路径**锁定**（`targetLocked`），之后任何自动匹配都不会覆盖它；
4. **多处同名** → 该行显示橙色感叹号，点它从**本地候选**里选一个；
5. **一个都没有** → 立刻弹本机选择器（按目标类型选文件或文件夹），选完绑到刚才那个目标上。

已绑定行的操作：**点一下 = 更换本地替换文件 / 挑源文件夹**；长按菜单 = 「更换本地替换文件（或更换本机源文件夹）/ 重新选择目标路径 / 手填完整路径 / 清除绑定」；包体模式还多一条「从列表移除」。

> 还没配本地文件的条目**不会进配方**（避免空 source），执行时会自动跳过它们。
